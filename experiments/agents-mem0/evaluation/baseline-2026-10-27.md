# First live Mem0 baseline — 2026-10-27

**Completed and reviewed as a retrieval baseline.** Correct evidence was present
for all 12 known-answer questions, but all three corrected-fact queries ranked
the outdated assertion above its replacement. This is a concrete reliability
gap in the current default retrieval/tool evidence, not an end-to-end assistant
accuracy score.

**Later clarification (D30):** the
[native correction follow-up](native-corrections-2026-10-27.md) confirms all
three old facts are superseded and linked to replacements; default reads retain
superseded history. Native latest_only=true excluded the old IDs and ranked
each current fact first. The original visible-record counts did not establish
that Mem0 had failed to supersede the old facts. Original evidence is preserved.

## Method and budget

Used [the frozen cases](cases.json) and [procedure](README.md): 30 fabricated
facts, three duplicate/paraphrase submissions, three corrections and 16 searches
under a new `whisper-stack-eval-*` owner. No real user facts, existing-owner
writes, deletion, app/agent settings changes or additional providers. Existing
app search behavior remained top_k=5 with provider defaults.

Signed-in Billing before: Free, model calls on Mem0, 1/10,000 adds and 5/1,000
retrievals. After: same coverage, 37/10,000 adds and 25/1,000 retrievals. The delta
matches 36 adds and 20 retrieval operations (16 searches plus four list reads).
All usage stayed within the included allowance; token/USD usage was not reported
by these calls. This is not a separately audited invoice.

The first process stopped after 22 completed writes because write 23 was still
RUNNING after six status checks. A later explicit read confirmed SUCCEEDED.
The continuation retained the owner/cumulative counters, checked that pending
job and submitted only the 13 untouched messages. No write was replayed. The
revised wait allows 20 checks; the 280-request global cap stayed unchanged.
Final cumulative ledger: **126 requests — 36 adds, 70 event reads, four list
reads and 16 searches**. No failed HTTP requests. This pause affects wall-clock
timing; do not interpret the full run duration as ingestion throughput.

## Reviewed findings

Review was performed by the assistant inspecting the captured records and all
16 result sets; there was no independent human reviewer or LLM judge call.

| Check | Observation | Interpretation |
| --- | --- | --- |
| Seed extraction | 30 stored records; all 30 supplied facts represented on inspection | Tiny synthetic sample only. Lexical coverage was 29/30 because the fixture's singular "Thursday" did not match stored "Thursdays"; cases were not edited after the run. |
| Three duplicate submissions | Still 30 records; seed and duplicate snapshots have identical ID/text mappings | Exact and paraphrased repeats added no visible duplicates in this sample. No claim about the responsible internal mechanism or Dream. |
| Three corrections | 33 records; both old and new assertions retained | Original lifecycle state was not captured; retention alone cannot establish whether superseding occurred. See D30 clarification above. |
| Nine unchanged known-answer queries | Correct supporting record ranked first in 9/9 | Includes direct, paraphrased and duplicate-related recall. |
| Three changed-answer queries | Correct supporting record ranked second in 3/3; outdated record ranked first in 3/3 | Top-five evidence coverage alone hides current-fact ambiguity. |
| Four unknown-answer queries | Each returned five records; none supported the requested answer | Nonempty retrieval does not establish answerability. Agent abstention was not tested. |
| Search latency | Median 304 ms; maximum 413 ms across 16 sequential searches | Single small-store sample, not a scale/latency benchmark. |
| Tool-result size | At most 339 UTF-8 bytes using the current strings-only projection | This does not establish an application size bound or a limit on cumulative session context. |

Correction examples:

- Drink: old "favorite hot drink is rooibos tea" ranked first (0.3967), new
  "favorite hot drink is chamomile tea" second (0.3887). The new record omitted
  the submitted correction's explicit "not rooibos" wording. The current tool
  strips dates/scores, so its two plain assertions do not explicitly say which
  is current.
- Town: old Bellmere ranked first (0.4335); Larkhaven second (0.4094). The new
  text does explicitly say the user moved away from Bellmere, providing a
  possible resolution if the answering model uses that wording correctly.
- Meeting: old Thursdays ranked first (0.4713); the change to Tuesdays second
  (0.3876). The change text also preserves the transition, but the older
  assertion remains in the tool response.

Unknown-query examples: a dog-name question returned the cat Juniper; an
employer question returned bicycle commuting; an allergy question returned lunch
and snack preferences; an access-code question returned the coding-project name.
These are distractors, not observed false assistant answers. The supported
Italian-language fact scored 0.2443, below the unknown employer query's top
distractor (0.2618); a single score cutoff would not perfectly separate this
sample's supported and unsupported answers.
